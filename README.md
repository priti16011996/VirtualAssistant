# Virtual Assistant – Personalized Voice Assistant

A full-stack virtual assistant application built using the MERN stack. It allows users to create an account, customize their assistant's profile image and name, and interact through voice-based input and speech responses.

## Overview

Virtual Assistant is a personalized assistant application designed to provide an interactive user experience.

Users can register and log in, customize their assistant's identity by selecting or uploading a profile image and choosing a preferred name. The application also uses browser-based speech recognition and text-to-speech technologies to enable voice interaction.

The project focuses on full-stack development, authentication, user-specific customization, image handling, and browser speech APIs.

## Application Workflow

### 1. Authentication Flow

1. User creates an account using registration.
2. Backend validates the provided information.
3. Password is hashed using bcrypt before saving.
4. User logs in with registered credentials.
5. Backend verifies credentials and generates a JWT.
6. JWT is stored in an HTTP-only cookie.
7. Authentication middleware protects private routes.
8. Authenticated user information is fetched from MongoDB.

### 2. Assistant Customization Flow

1. User logs into the application.
2. User navigates to the assistant customization page.
3. User selects an image from the predefined options or uploads a custom image.
4. Selected image is previewed.
5. User enters a preferred assistant name.
6. User saves the customization.
7. Frontend sends the updated information to the backend.
8. Backend updates the user's assistant profile in MongoDB.
9. The customized assistant name and profile image are displayed dynamically.

### 3. Voice Interaction Flow

1. User activates the microphone.
2. Browser Speech Recognition API captures the user's voice.
3. Speech is converted into text.
4. The application processes the recognized input.
5. A response is generated by the application's configured response logic.
6. SpeechSynthesis API converts the response text into spoken audio.

## Browser APIs

### Web Speech Recognition API

Used to capture voice input and convert speech into text.

```javascript
const SpeechRecognition =
    window.SpeechRecognition ||
    window.webkitSpeechRecognition;

const recognition = new SpeechRecognition();

recognition.lang = "en-IN";
recognition.continuous = false;
recognition.interimResults = false;

recognition.onresult = (event) => {
    const transcript =
        event.results[0][0].transcript;

    console.log("Recognized Speech:", transcript);
};

recognition.onerror = (event) => {
    console.error("Speech Error:", event.error);
};

recognition.start();
```

### SpeechSynthesis API

Used to convert text into spoken responses.

```javascript
const speak = (text) => {
    const utterance = new SpeechSynthesisUtterance(text);

    utterance.lang = "en-IN";
    utterance.rate = 1;
    utterance.pitch = 1;

    window.speechSynthesis.speak(utterance);
};

speak("Hello! How can I help you?");
```

## Installation & Setup

### Prerequisites

- Node.js (v18 or later)
- MongoDB
- Git
- Modern browser supporting the Web Speech API

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>

cd Virtual-Assistant
```

### 2. Backend Setup

Navigate to the backend directory:

```bash
cd backend

npm install
```

Create a `.env` file inside the backend directory:

```env
PORT=5000

MONGO_URL=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret
```

Start the backend development server:

```bash
npm run dev
```

### 3. Frontend Setup

Open another terminal:

```bash
cd frontend

npm install
```

Create a `.env` file inside the frontend directory:

```env
VITE_SERVER_URL=http://localhost:5000
```

Start the frontend development server:

```bash
npm run dev
```

Open the application:

```text
http://localhost:5173
```

*Note: Environment variable names and commands should match your actual application configuration.*
